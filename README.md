## 🎨 Style Foundations Summary

- **Visual Style**: Minimal, utility-first, accessibility-prioritized
- **Typography**: `Work Sans`, bold display typography (scale: 12px to 100px)
- **Palette**:
  - Surface Base: `#000000`
  - Text Secondary: `#0000ee`
  - Surface Muted: `#ffffff`
  - Accent / Inverse: `#f56e0f`
- **Accessibility Target**: WCAG 2.2 AA compliant
